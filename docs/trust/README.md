# Trust and assurance documents

Buyer-facing assurance material: the documents an enterprise or public-sector
procurement pack asks for, written so they can be sent as-is rather than
assembled from scratch each time. They are deliberately separate from the
internal security notes (`docs/security-audit-playbook.md`,
`docs/security-exceptions.md`), which describe *how we work* rather than *what
we commit to*.

| Document | What it answers |
|---|---|
| [vulnerability-management.md](vulnerability-management.md) | Per-severity remediation SLA, the path when there is no upstream fix, who decides, and the scanning cadence. Also states which findings the CI gate blocks on, and why exactly those (#2059) |

Related evidence that lives outside this folder because it is generated or
already had a home:

| Artefact | Where |
|---|---|
| CycloneDX SBOM (production dependencies, stamped with version + commit) | `/sbom.cdx.json` on any deployed environment; generated by `npm run gen:sbom` in `build-image.yml` |
| Third-party licence inventory | [`docs/legal/third-party-licenses.md`](../legal/third-party-licenses.md) |
| Accepted dependency findings and their written reasons | [`docs/security-exceptions.md`](../security-exceptions.md) |
| Security model, reporting process and response targets | [`SECURITY.md`](../../SECURITY.md) |

Two siblings are planned and not written yet: a `security-overview.md`
summarising the security model for a non-engineering reader
([#2027](https://github.com/21072026/Internship/issues/2027)) and the `/trust`
page that publishes this material — plus the VPAT and the DPA — in the app
([#2031](https://github.com/21072026/Internship/issues/2031)). When `/trust`
ships, its assurance section links every row of both tables above; until then
those paths are the canonical answer to send.

**Rule for anything added here**: it is read by people outside the project, so
no internal hostnames, no ticket shorthand without a link, and no claim that is
not already true in the repository. The sole rights holder is **Mehmet Erşahin**,
