## 2026-10-07 — VPAT 2.5 generated from the repository's evidence (#2037)

- **Check the issue's "gaps" against the tree before writing a conformance row.** #2037 (filed
  2026-08) said no `prefers-reduced-motion`, no 320 px test and two unnamed selects; by now
  #2045, #2047 and #2041 had landed. Three rows the issue wanted at *Does Not Support* are
  *Supports* with evidence. `grep` first, then write the remark.
- **Markdown is not in the image** (`.dockerignore` has `*.md`), so "serve the file from
  `public/`" does not work for a `.md`: the public artefact has to be rendered from code. The
  data lives in a TS module, the page and a `vpat.md` route render it, and the committed
  `docs/legal/vpat.md` is a generated copy the unit test compares byte for byte.
- **A pure renderer shared by Node scripts and the app must import only types.**
  `--experimental-strip-types` erases `import type`, so `src/lib/vpatRender.ts` can be imported
  by `scripts/*.mjs` and by the page alike; anything with `@/` or an extensionless relative
  import cannot. The `@/`-importing assembler (`vpatDocument.ts`) is therefore a separate file
  the script does not use — the script and the test build the same shape by hand.
- **Stamp generated docs with the input's commit, not with "now".** The appendix carries the
  commit that last changed `e2e/a11y-baseline.json` (`git log -1 --format=%H%n%cI -- <file>`),
  so a regenerate that changes nothing produces no diff and the drift test stays meaningful.
- **Dictionary anchors: a key name is rarely unique.** `imprintLink:` occurs in seven
  namespaces; anchor on the namespace opening line (`\n  accessibility: {\n`) instead.
- **A single-character shortcut is a 2.1.4 row.** `src/lib/shortcuts.ts` binds `?` to the
  shortcut sheet with no way to turn it off or remap it — honest answer: *Partially Supports*,
  tracked in #2864.
- **A quoted shell command in evidence is a test waiting to be run.** The first version
  stated `grep … returns nothing` seven times and never ran them; executing them in the unit
  test found three false claims at once (`autoplay` matched a muted clip's comment and an
  iframe `allow` list, `animate-bounce` did not exist but `animate-ping` did, and a grep
  found its own quotation in `src/lib/vpat.ts`). Make the claim machine-checkable
  ("returns nothing", "lists … only"), exclude the data file, and let the test run it.
- **CodeQL reads a Markdown escaper as a sanitizer.** `cell()` escaping `|` but not `\`
  is flagged as *Incomplete string escaping* (js/incomplete-sanitization) on the PR, and
  the alert is a failing required check. Double backslashes first; keep backslashes out of
  the data (use `grep -E "a|b"` instead of BRE `a\|b`) so code spans still render as typed.
