## 2026-10-07 — shared session minutes beside two private note models (#1847)

- **"Do not widen the private model" is a third-model problem, and the regression test belongs in the new feature's spec.** `PersonalNote` kept its author-only read path untouched; the proof is in `e2e/session-notes.spec.ts` itself — the mentor's private note is created against the same pairing the shared minutes live on, and the mentee's `GET /api/notes`, `PATCH` and `DELETE` are asserted in the same run. A separate "notes still private" spec would have drifted from the people it is about.
- **An append-only revision trail is cheapest when revision[0] is always the current body.** `recordRevision()` runs after every create and every edit, so `lastEditedBy` is `revisions[0].author` with no extra column, and "saving identical text is not an edit" is one string comparison in the route. Trim with `skip: N` + `deleteMany` rather than a counter.
- **A second relation-scoped realtime event copies the first one's four touch points exactly** (`realtimeBus` type, `realtimeClient` union + `addEventListener`, the stream's `pushCounts` exclusion, `MessagesLiveRefresh`'s ignore list). Keep the comment on each saying "same contract as `agenda`" so the next one is a copy, not a design.
- **Account erasure has to learn every new free-text model that is *about* the subject.** `src/lib/accountErasure.ts` tombstones by `asSubject = { relation: { menteeId } }`; the shared minutes and their revisions joined `relationNote` there in the same commit. Grep that file whenever a `@db.Text` column lands on a relation child.
- **The container's MariaDB does not survive a worker restart; `db push` then fails with "make sure your database server is running".** `service mariadb start` first, every time the session resumes, before any Prisma command that touches the database.
- **`scripts/test/schema-push-safety.test.mjs` → "the CLI fails on the real #2249 commit" is red in this container on unmodified `main` too** (the CLI reports "compared against origin/main" although the test sets `SCHEMA_PUSH_SAFETY_BASE`), and it only runs once the clone can reach `aa257b2` — so it starts failing mid-session after enough fetches. CI's full-history checkout is green on it. Confirm against `origin/main` before chasing it in a feature branch.
