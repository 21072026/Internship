# 2026-10-28 — Group sessions on the calendar and in the journey (#1856, 3/4)

- **After every rebase onto main: `npx prisma generate` and `node scripts/i18n-scopes.mjs`.**
  Siblings add models (a stale client fails `orgContext.ts`'s `TENANT_MODELS` type) and
  `src/i18n/scopes.generated.ts` is gitignored, generated by postinstall/dev/build — a fresh
  checkout without it fails `tsc` on `src/i18n/scope.tsx`.
- **A conflict resolver that keeps "both sides" can duplicate an object key** when a sibling
  edited the line next to yours (here a feature card's `calendar` text): `tsc` reports TS1117
  "multiple properties with the same name". Keep main's copy of the line you did not author.
- A journey step's payload is a whitelist in `readStepPayload()`; a new field there also
  needs the PATCH route's "merge current payload" list in
  `src/app/api/admin/programs/[id]/journey/[stepId]/route.ts`, or editing an unrelated field
  of the step silently drops it.
- `/api/cron?job=program-journey` runs the sweep for the caller's own org as an org ADMIN —
  the cheapest way for an e2e spec to deliver a step for real.
