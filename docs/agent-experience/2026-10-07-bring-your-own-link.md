## 2026-10-07 — bring your own conferencing link, org policy, personal room (#2007)

- **Splitting a Prisma model block with a blank line realigns everything above the split.** `prisma format` pads each blank-line-separated group to its own widest field name and type. Putting `conferencingPolicy` in its own group *between* `publicHost` and `createdAt` moved `DateTime` (the widest type) out of the first group, so 47 untouched `Organization` and `User` lines re-padded. Add a new field **inside** the existing group (a comment line above it does not break the group) when its name is shorter than the group's widest, or append the new group **after** the last scalar. The diff went from 73+/47− to 24+/0−.
- **`npx prisma validate` prints `Environment variable not found: DATABASE_URL` as an error** with no `.env` in the container — exit code still 0 and the schema is fine. Set a dummy `DATABASE_URL` for `prisma validate`, `tsc`, `lint` and every `check:*` script, or the log looks red.
- **Playwright's test process does not read `.env`.** The dev server it boots does (Next loads it), so the app had a database while `e2e/helpers/db.ts`'s own `PrismaClient` threw `Environment variable not found: DATABASE_URL`. Export `DATABASE_URL` in the shell that runs `npx playwright test`.
- **Playwright 1.63 wants `chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell`; `/opt/pw-browsers` has `-1194` with the old `chrome-linux/headless_shell` layout.** A directory symlink is not enough (different inner path). Create the expected directories and link every file of `chromium_headless_shell-1194/chrome-linux/` into `chromium_headless_shell-1243/chrome-headless-shell-linux64/`, with `headless_shell` linked as `chrome-headless-shell` (the `.pak`/`.dat` siblings must be beside the binary), plus an `INSTALLATION_COMPLETE` marker; same for `chromium-1243/chrome-linux64/`.
- **`check:openapi` classifies an `/api/admin/**` route as "public" when the ADMIN check lives in a helper in another file** (`orgAdminRefusal` from `src/lib/orgAdminGate.ts`). The analyser follows same-file functions only. Keep the literal `if (!session) 401` / `if (session.user.role !== 'ADMIN') 403` lines in the handler, as `[id]/starter-pack/route.ts` does, and call the gate after them.
- **Nine e2e specs with `--reporter=list` piped through `grep | tail` exceed the 10-minute foreground limit and the kill leaves no output.** Run a multi-spec batch in the background with the reporter writing to a file, and read the file.
- **A MARKETING-safe wording for conferencing strings:** "organizer", "organization", "built-in room" — no mentor/mentee words were needed in 30 new keys, so the `check:i18n` leak ratchet (`EXPECTED_LEAKS`) did not move.
- **Validating a URL that only people open is not an SSRF question.** `assertPublicHttpsUrl` resolves DNS and rejects private ranges, which would refuse a company's intranet Jitsi. The right check for a meeting link is https + no credentials + not a served host + fits the column (`checkExternalMeetingLink`), and a `Meeting.meetLink` is `VARCHAR(191)`, so a Teams link over 191 chars must be a `400 too_long`, not a P2000 500.
