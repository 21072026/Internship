## 2026-10-07 — AI_PACKAGE gates operator AI; parallel implementers in worktrees (#1738, #2857)

- **A workflow agent that dies on the account's session limit leaves its worktree with uncommitted edits — harvest them, do not redo them.** `git worktree list` shows the agents' trees; `git -C <worktree> diff > x.patch && git apply -3 x.patch` on your branch takes the tracked changes, `cp` the untracked new files, then `git worktree remove --force` and delete the `worktree-wf_*` branches. Two of three implementers had finished the work and only failed at the commit step.
- **Fix the contract in code before fanning out.** The gate change (`not_entitled`, `AI_PACK_FEATURE`, the audience table) went in as one commit first; the route, docs and e2e implementers then compiled against it instead of against a prose description. Disjoint file sets per implementer meant the three diffs applied without a single conflict.
- **A stacked branch on a squash-merged base: `git rebase --onto origin/main <old-base-sha> <branch>`**, not `git merge origin/main` (that conflicts on every file the merged PR touched, even with identical content). Confirm first that `git diff <old-base-sha> origin/main -- <your files>` is empty. Then `npx prisma generate` if main's schema moved — the shared client under `node_modules` is whatever was generated last.
- **The worker process restart stops MariaDB.** `Can't reach database server at 127.0.0.1:3306` in a check script after a restart is `service mariadb start`, not a code problem.
- **A `cd` into an agent's worktree in a Bash call flips the session's primary working directory** (an "Environment update" follows). Use `git -C <path>` for one-off reads of another tree and keep `cd /home/user/Internship` explicit afterwards.
- **The repo's answer to "turning on a gate takes a feature away from everyone" is a run-once grandfather backfill** (`prisma/backfill-report-export-grandfather.mjs`): grant every existing org, stamp a marker note, and let later runs no-op when the marker exists. Prove it against the seeded local database: dry run → first run grants → second run says "already ran". The demo seed grants the pack itself, because topic environments start from an empty database.
- **The gate asks for the pack before the artefact cache, and the GET-side peeks that bypass the gate must say the same thing** (`insightsResponse`, `analyticsNarrative` read `locked` from the same `settingsOrgOf` org the gate meters), or a locked org reads a stored copy on GET and is refused on POST.
- **e2e specs on operator AI need their own org to hold the pack.** `setOrgFeature(orgId, 'AI_PACKAGE', true)` from `e2e/helpers/db.ts`, and `prisma.orgEntitlement.deleteMany` in the cleanup before the org delete (the FK otherwise keeps the org alive). Never toggle the shared default org's grant off: other specs run on it in parallel.
