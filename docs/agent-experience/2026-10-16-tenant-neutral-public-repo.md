## 2026-10-16 — making the repo tenant-neutral before it went public again (#2919, #2921, #2924, #2925, #2934, #2935, #2938, #2940, #2942)

- **A tenant name hides in far more places than the tree.** Besides files and file names it sat in commit messages, branch names, PR and issue titles/bodies, bot comments (the topic-preview template kept re-adding it to every new PR), Actions run titles, artifacts (Playwright reports with screenshots, Docker build records with the route list), deploy/uptime logs that printed a page `<title>`, release notes linked to commits, and 72 landing screenshots in pixels. Fix the generators first, then scrub.
- **A PR cannot be deleted or transferred, and a renamed title stays in its timeline.** Issues can be transferred (`gh issue transfer N owner/other-repo`) to a private repo of the same owner; PR text can only be edited, and edit history stays visible to readers.
- **GitHub search misses substrings** (`Name's`, `nameIngest`). Page through `/issues?state=all`, `/issues/comments` and `/pulls/comments` with `gh api --paginate` and grep locally instead.
- **`git grep -E` has no `\b`.** A word-boundary pattern silently matches almost nothing; use `git grep -P`. JS regexes (the guard) do support `\b`.
- **zsh does not split `$VAR` into words.** `git checkout --theirs $FILES` with a space-separated list passed ONE path, failed, and the following `git add -A` committed conflict markers. List the files literally or use an array.
- **Moving a hardcoded value to data without a visible change takes three steps:** ship the DB path with the old constant as fallback (diff adds no tenant name), write the data in prod, then delete the constant. Verify each step by diffing the served manifest and `<head>` against a baseline captured before the merge.
- **A brand set can be rendered offline and inserted, when nobody can sign in to upload it:** run the app's own renderer with `npx tsx --tsconfig tsconfig.json` on a detached worktree, then insert the rows from inside the container with the app's Prisma client.
- **Keep the forbidden-term list in a secret, never in the repo,** and make the guard print locations only — GitHub masks only the exact secret string, so any other spelling would be echoed into a public log.
- **A private repo on the Free plan meters Actions minutes;** when the spending limit is hit every hosted job fails before it starts ("recent account payments have failed"), deploys included, because the image is built on a hosted runner.
- **Postfix `450 4.7.1 too much mail from <ip>` is the relay's per-client rate limit (anvil),** not a provider block. Every environment on the box shares one IP; exempt it with `smtpd_client_event_limit_exceptions` and pace mail in the app.
