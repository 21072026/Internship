## 2026-10-07 — minutes become the meeting log, action items become to-dos (#1849)

- **Two-way sync between a text and a row is three one-way bridges, none of which goes through an HTTP handler.** `minutesSync.ts` is called from the write that changed one side (session-note POST/PATCH → the log row and the to-dos; task PATCH → the minutes line) and writes the other side with Prisma directly. Because no bridge calls a route, there is no loop to guard against, and each bridge is unit-sized.
- **Identify a text line by its normalized text, not its index.** Minutes get edited and lines move; `SessionNoteActionItem.text` is the line as promoted, `findActionItem()` matches on `normalizeActionText()` (trim, collapse spaces, lowercase). A line that was deleted leaves its to-do alone — the to-do is still work somebody owns.
- **"Prefer the real content" in a sweep is a select + a fallback, never a second write path.** `loggableSelect` gained `sessionNotes: { take: 1, orderBy: createdAt desc }` and `notesFor()` picks `body || placeholder`; the caps and the lookback window did not move, and the P2002 guard still makes click vs sweep a non-event.
- **A Python heredoc turns `’` into the real character before it reaches the file.** An anchor written as `pair’s` in a later edit then fails to match; anchor on ASCII-only text (the locale-distinct tail of the same line) or use a regex.
- **`check:i18n` only sees keys that exist in all three locales; `tsc` is what tells you a key is missing from the dictionary the component reads.** Run `tsc` right after a dictionary edit — "Property 'x' does not exist on type …" lists exactly the keys the insertion missed.
